# Unlim favorite stickers

Плагин для [exteraGram](https://exteragram.app) убирающий лимит на добавление стикеров в избранные

> [!CAUTION]
> Стикеры сохраняются только локально, без синхронизации между устройствами

Скачать: [релизы](https://github.com/TelePlug/unlim-favorite-stickers/releases)

## Бекап

Избранное хранится только на устройстве, поэтому его стоит выносить наружу.
На сервере лежат лишь первые несколько стикеров — всё, что сверх лимита,
существует в одном экземпляре.

В настройках плагина две кнопки: «Экспорт текущего аккаунта» и «Экспорт всех
аккаунтов». Обе отправляют файл `.stickers` в «Избранное» — оттуда он доступен
с любого устройства.

Чтобы восстановить, откройте этот файл в любом чате: плагин предложит добавить
стикеры к текущим или заменить их. Перед заменой прежнее избранное само уходит
в «Избранное» отдельным файлом, так что откатиться можно тем же способом —
открыть слепок и выбрать «Заменить».

Файл экспорта одного аккаунта не содержит идентификаторов, им можно поделиться,
чтобы передать подборку другому человеку. Экспорт всех аккаунтов содержит ваши
user id и предназначен только для себя.

Если тап по файлу `.stickers` открывает его обычным просмотрщиком вместо
предложения импорта, значит в вашей сборке не удалось перехватить открытие
файлов — подробности будут в логе по префиксу `[favstickers]`.

## Для разработчиков
### Тесты
Логика базы и хуков проверяется без телефона — Java подменена стабами:
```
python tests/test_plugin.py
```
Тесты с `KNOWN_GAP` в имени фиксируют известные незакрытые дыры: они упадут, когда дыру закроют, — значит, тест пора переписать.

### debug run
```
uv run extera ./unlim_favorite_stickers.plugin --debug

adb logcat | grep "D \[PyObject\]"
```

### Кеширование стикеров
Для кеширования и отправки стикера достаточно хранить:
- sticker.id
- sticker.dc_id
- sticker.access_hash

Чтобы он сразу красиво отображался при отправке:
- mime_type

Чтобы можно было восстановить access_id:
- stickerset_id
